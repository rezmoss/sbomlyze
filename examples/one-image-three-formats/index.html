One image, three formats

The same nginx image as Syft JSON, CycloneDX and SPDX diffs to nothing in every pairing, while their compliance scores differ: NTIA 57, 71 and 71.

containerdeb Cross-format diffCompliance scoringFormat conversion

What happened

Teams end up with SBOMs in more than one format. Diffed naively, the same image looks different in each: CycloneDX lists files as components, SPDX folds license names into LicenseRef- ids, and only some formats record file ownership or the OS. sbomlyze reads each one into the same model, so the three versions of one scan compare as identical.

They are not equally complete, though. The same scan scores differently against the NTIA, CISA and BSI minimum elements depending on the output format: Syft JSON has no document timestamp, which costs it the NTIA timestamp check. Other checks differ too: the SPDX carries a supplier for 74 of the 150 packages, the Syft JSON and CycloneDX for 149. The per-check results are in the full output.

What this does not prove. A score measures which minimum elements the document carries, not whether the data in them is right.

Inputs

Generated once with Syft 1.56.0, linux/amd64, and kept unchanged in testdata/showcase in the repository. Every sbomlyze release re-runs the commands below on these exact files.

nginx:1.28.0, built 8 Dec 2025
