sbomlyze v0.8.0: example output

Output of sbomlyze v0.8.0 on the SBOMs in testdata/showcase.

Same tag, different image

nginx:1.28.0 built in April and in December 2025 both run nginx 1.28.0, but 40 Debian packages differ, including the OpenSSL fix for CVE-2025-9230.

  • Diff (Syft JSON): sbomlyze nginx-1.28.0-apr.syft.json nginx-1.28.0-dec.syft.json (exit 1): text json markdown html sarif junit patch
  • Same diff from CycloneDX: sbomlyze nginx-1.28.0-apr.cdx.json nginx-1.28.0-dec.cdx.json (exit 1): text
  • Same diff from SPDX: sbomlyze nginx-1.28.0-apr.spdx.json nginx-1.28.0-dec.spdx.json (exit 1): text

Go module re-tagged after release

The same go-containerregistry v0.20.4, two different checksums: the maintainer moved the tag after Go's checksum database had recorded it.

  • Diff of the two builds: sbomlyze ggcr-checksum-db.syft.json ggcr-goprivate.syft.json (exit 1): text json markdown html sarif junit patch
  • With deny_integrity_drift: sbomlyze ggcr-checksum-db.syft.json ggcr-goprivate.syft.json --policy policy-integrity.json (exit 1): text
  • Control: syft 1.55.0 → 1.57.0: sbomlyze syft-1.55.0.syft.json syft-1.57.0.syft.json (exit 1): text
